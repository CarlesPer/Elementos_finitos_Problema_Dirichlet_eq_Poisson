# Elementos_finitos_Problema_Dirichlet_eq_Poisson
En este proyecto hemos desarrollado el método de elementos finitos para dos dimensiones con funciones continuas y lineales a trozos en una triangulación T en un abierto Ω ⊆ R2, para resolver el problema de Dirichlet que tiene por término fuente la ecuación de Poisson y con condiciones de frontera no homogéneas.
